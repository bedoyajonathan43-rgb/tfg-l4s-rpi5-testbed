# Comprobaciones de desarrollo

Scripts de un solo uso, con la salida que dieron (`.txt`), hechos mientras se ponía a punto el entorno: selección del algoritmo de congestión, marcado en la RLC del gNB, tamaño de la cola y reparto de núcleos. No hacen falta para repetir las campañas. Se dejan como registro de lo que se comprobó.

`actualizar_campana.py` adaptó en su momento el lanzador y el resumen al gNB con marcado. Las versiones de `campanas/` ya incluyen ese cambio.
